
# 🏥 Insurance Cost Prediction

## Project Overview
This project predicts medical insurance charges using Machine Learning regression algorithms.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
- Streamlit

## Machine Learning
Multiple regression models are explored to predict insurance costs. Model evaluation is used to compare their performance.

## Features
- User-friendly Streamlit interface
- Customer details as input
- Estimated insurance charges as output

## Project Files
- `Insurance Cost Prediction.ipynb` — Model development and analysis
- `app.py` — Streamlit application
- `requirements.txt` — Required libraries
- `model.pkl` — Saved trained model
- `scaler.pkl` — Saved feature scaler
- `columns.pkl` — Model input columns
- `model_evaluation.txt` — Evaluation results

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

## Disclaimer
Predictions are estimates and are not actual insurance quotes.
